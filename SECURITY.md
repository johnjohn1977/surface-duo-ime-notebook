# Security policy

## Supported versions

This project is an experimental prototype. Security fixes are applied only to
the latest commit on `main`; there are no supported release branches yet.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting from the repository **Security**
tab. Do not open a public issue for a problem that could expose typed content,
Accessibility data, credentials, device identifiers, or signing material.

Include a concise impact statement, reproduction steps, the affected commit,
and a minimal redacted log if one is necessary. Do not include real typed
content or unredacted device data.

The maintainer will acknowledge the report when it is reviewed and will keep
technical details private until a fix or safe mitigation is available.
